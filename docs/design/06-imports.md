# 06 — Imports

## Top bar (this panel)
Title « Imports » + descriptor « Relevés OFX et QFX — traités sur cet ordinateur ». Right: user pill only — the panel carries no account selection of its own.

## Content layout
Region A « Nouvel import » (Card, left, flex 1.35): **no destination select** — a statement declares its own account, so the panel reads the destination out of the file. DropZone « Déposez un fichier OFX ou QFX » / sub « ou cliquez pour parcourir — le relevé indique lui-même son compte ». Under the title sits the detected-account notice: a green InlineBanner naming the account when the file resolved to one; an amber banner **plus a 340 px account select (with monogram)** when it didn't — either because several of the user's accounts match the bank the file names (the select is scoped to those candidates only) or because the file declares no account at all (the select then lists every account). An amber banner with a « Créer ce compte » action when the statement describes an account that doesn't exist yet, which opens the prefilled account form. File-selected variant: iris-tinted dashed row with OFX format badge, filename + size, remove ×, and primary « Importer » — **disabled until a destination is settled**, the notice above always saying what is missing. Region A' result Card (right, only after an import): « Dernier import » + Réussi status pill, two inset count plates (42 nouvelles / 3 doublons ignorés), coverage line 01/05/2026 – 31/05/2026 and file→account line. Region C « Historique des imports » (Card, fills remaining height): DataTable Fichier · Format badge (OFX blue / QFX violet) · Importé le · Période couverte · Nouvelles · Doublons · Statut pill (Réussi green / Partiel amber / Échec red); notes render as a second line under the filename (amber dup note, red failure message).

## States to show
① file selected + result (fr). ② detected account (fr) — green banner « Compte reconnu dans le fichier : Compte courant », no select at all. ③ ambiguous (fr) — amber banner + select limited to the two matching accounts, Importer disabled until one is picked. ④ unknown account (fr) — amber banner + « Créer ce compte », then the prefilled account form over the panel. ⑤ history (fr) — 5 batches incl. Partiel-with-dups and Échec. ⑥ empty history (fr) — EmptyState inside Region C, DropZone above stays available.

## Notes
Failure copy is calm and states nothing was modified. The panel never guesses a destination: with no selector and no default account, an unresolved file leaves the import disabled rather than filing a statement somewhere nobody chose.
